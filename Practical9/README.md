# Практическая работа 9

Порядок открытия и сборки описан в [общем README](../README.md). Ниже приведены классы для запуска, примеры и объяснения алгоритмов.

## 1. Сортировка вставками

Класс для запуска — ru.mirea.block2.practical9.TestStudent.

Берём очередного студента. Всех студентов слева с большим номером сдвигаем на одну позицию вправо. В освободившееся место ставим выбранного студента. После каждого шага левая часть массива упорядочена.

Программа использует данные, заданные в main.

Результат или его основная строка

```text
101 Белов
102 Соколова
103 Крылова
```

## 2. Быстрая сортировка по баллам

Класс для запуска — ru.mirea.block2.practical9.SortingStudentsByGPA.

Выбираем опорного студента из середины массива. Два индекса идут с разных сторон и меняют местами студентов, стоящих не по порядку. Затем таким же способом сортируем обе части массива. Метод compare задаёт убывание баллов.

Программа использует данные, заданные в main.

Результат или его основная строка

```text
Соколова 96.0
Крылова 91.0
Белов 84.0
```
