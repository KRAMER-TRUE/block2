## 1. Класс Student

Класс для запуска — ru.mirea.block2.practical10.StudentDemo.

Поля хранят данные студента. Конструктор заполняет их через сеттеры. Геттер возвращает значение, а сеттер проверяет и записывает новое. Метод required убирает крайние пробелы и проверяет четыре обязательных текстовых поля. Курс и номер положительные, балл конечный и неотрицательный. Верхняя граница балла не задаётся.

Программа использует данные, заданные в main.

Результат или его основная строка

```text
Анна Крылова, Информатика, курс 2, группа КВБО-11-25, ID 103, балл 91.0
Новый курс: 3
```

## 3. Объединение списков студентов

Класс для запуска — ru.mirea.block2.practical10.MergeStudents.

Создаём два ArrayList со студентами. Копируем первый в общий список и добавляем второй через addAll. Вызываем sort с объектом MergeStudents. Его метод compare сравнивает фамилии. Обычный цикл for выводит результат.

Программа использует данные, заданные в main.

Результат или его основная строка

```text
Иван Белов, Информатика, курс 2, группа КВБО-11-25, ID 101, балл 84.0
Елена Волкова, Информатика, курс 2, группа КВБО-12-25, ID 104, балл 88.0
Анна Крылова, Информатика, курс 2, группа КВБО-11-25, ID 103, балл 91.0
Ольга Соколова, Информатика, курс 2, группа КВБО-12-25, ID 105, балл 96.0
```
