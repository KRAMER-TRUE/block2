# Практическая работа 14

Порядок открытия и сборки описан в [общем README](../README.md). Ниже приведены классы для запуска, примеры и объяснения алгоритмов.

## 1. Разбиение строки на элементы

Класс для запуска — ru.mirea.block2.practical14.Task1.

Метод split разбивает строку по пробелам, запятым и точкам с запятой. Знак + в шаблоне объединяет соседние разделители. Цикл выводит непустые части с номерами.

Пример ввода

```text
red, green; blue
```

Результат или его основная строка

```text
1. red
2. green
3. blue
```

## 2. Точное совпадение строки

Класс для запуска — ru.mirea.block2.practical14.Task2.

Метод matches сравнивает всю строку с заданным регулярным выражением. При полном совпадении выводим подтверждение, иначе сообщаем, что строка не совпадает.

Пример ввода

```text
abcdefghijklmnopqrstuv18340
```

Результат или его основная строка

```text
Строка совпадает.
```

## 7. Проверка пароля

Класс для запуска — ru.mirea.block2.practical14.Task7.

Первая проверка разрешает только английские буквы, цифры и подчёркивание и требует минимум восемь символов. Ещё три проверки ищут заглавную букву, строчную букву и цифру. Пароль подходит, когда все четыре условия истинны.

Пример ввода

```text
F032_Password
```

Результат или его основная строка

```text
Пароль надёжный.
```

В условии указан минимум восемь символов. Поэтому пример TrySpy1 из методички содержит недостаточно символов и отклоняется.

## 9. Частотный словарь букв

Класс для запуска — ru.mirea.block2.practical14.Task9.

Проходим по символам текста обычным циклом. Заглавную английскую букву переводим в строчную. У каждой буквы есть свой счётчик в массиве из 26 элементов. Индекс равен letter минус a. Второй цикл выводит буквы с ненулевыми счётчиками по алфавиту.

Пример ввода

```text
Banana!
```

Результат или его основная строка

```text
a — 3
b — 1
n — 2
```
