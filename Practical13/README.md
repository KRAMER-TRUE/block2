# Практическая работа 13

Порядок открытия и сборки описан в [общем README](../README.md). Ниже приведены классы для запуска, примеры и объяснения алгоритмов.

## 1. Методы класса String

Класс для запуска — ru.mirea.block2.practical13.task01.Task1.

Метод show получает строку и по очереди вызывает charAt, endsWith, startsWith, contains, indexOf, replace, toUpperCase, toLowerCase и substring. Пустую строку проверяем до обращения к последнему символу. Подстроку Java вырезаем только при найденном индексе.

Пример ввода

```text
I like Java!!!
```

Результат или его основная строка

```text
Подстрока: Java
```

## 3. Разбор адреса

Класс для запуска — ru.mirea.block2.practical13.task03.Task3.

Первый метод делит строку по запятым через split. Второй использует StringTokenizer с запятой, точкой и точкой с запятой. Для второго способа считаем шесть разделителей обычным циклом и получаем семь частей. Конструктор проверяет части, убирает крайние пробелы и записывает семь полей.

Программа использует данные, заданные в main.

Результат или его основная строка

```text
Беларусь, Минская область, Минск, Немига, 3, 2, 16
```

## 5. Форматирование номера телефона

Класс для запуска — ru.mirea.block2.practical13.task05.Task5.

Проверяем номер по одному из двух форматов из задания. Последние 10 цифр — сам номер. Всё между плюсом и этими цифрами — код страны. Для номера с первой цифрой 8 ставим код 7. Через substring разбиваем номер на группы 3, 3 и 4 цифры и соединяем их дефисами.

Пример ввода

```text
89175655655
```

Результат или его основная строка

```text
+7917-565-5655
```

## 6. Цепочка слов из файла

Класс для запуска — ru.mirea.block2.practical13.task06.Task6.

Массив used отмечает использованные слова, а order хранит их номера в цепочке. Метод arrange перебирает слова для очередного места. Слово подходит, если оно ещё не использовано и его первая буква совпадает с последней буквой предыдущего. Выбираем его и пробуем заполнить следующее место. Если продолжения нет, снимаем отметку used и пробуем другое слово. Когда заполнены все места, getLine собирает ответ через StringBuilder.

Например, в наборе «кот комок» выбор «кот» первым приводит в тупик. Программа отменяет этот выбор и получает «комок кот». Одинаковые слова отмечаются по разным индексам, поэтому каждое вхождение используется отдельно.

Перебор в худшем случае проверяет до n! порядков и может работать долго на большом наборе слов. Метод перебирает все подходящие варианты и возвращает пустую строку, только если цепочки нет. Глубина рекурсии равна количеству слов и ограничена стеком Java. Ограничение на количество слов в коде не вводится.

firstLetter и lastLetter получают первую и последнюю буквы без учёта регистра. Два вызова codePointAt и codePointBefore сохранены, чтобы корректно читать также буквы, которые в Java занимают две позиции строки.

При запуске из Practical13 введите words.txt. При запуске из корня Block2 введите Practical13/words.txt или полный путь. Файл читается в UTF-8. Пробелы, табуляция и переносы строк разделяют слова.

Пример ввода

```text
words.txt
```

Результат или его основная строка

```text
Груша ананас Слива абрикос
```
