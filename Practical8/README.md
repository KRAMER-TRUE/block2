# Практическая работа 8

Порядок открытия и сборки описан в [общем README](../README.md). Ниже приведены классы для запуска, примеры и объяснения алгоритмов.

## 5. Сумма цифр числа

Класс для запуска — ru.mirea.block2.practical8.Task5.

Последняя цифра числа равна остатку от деления на 10. Деление на 10 убирает эту цифру. Прибавляем её к сумме остальных цифр, которую находит тот же метод. Для однозначного числа возвращаем само число.

Пример ввода

```text
5072
```

Результат или его основная строка

```text
14
```

## 8. Палиндром

Класс для запуска — ru.mirea.block2.practical8.Task8.

Сравниваем первую и последнюю буквы. Если они разные, ответ NO. Если одинаковые, проверяем следующую пару ближе к середине. Когда границы встретились или пересеклись, ответ YES. Циклов в алгоритме нет.

Пример ввода

```text
level
```

Результат или его основная строка

```text
YES
```

## 14. Цифры числа слева направо

Класс для запуска — ru.mirea.block2.practical8.Task14.

Сначала вызываем метод для числа без последней цифры. После возврата печатаем последнюю цифру. Поэтому цифры появляются слева направо. У однозначного числа сразу печатается его единственная цифра.

Пример ввода

```text
5072
```

Результат или его основная строка

```text
5
0
7
2
```
