# Практическая работа 11

Порядок открытия и сборки описан в [общем README](../README.md). Ниже приведены классы для запуска, примеры и объяснения алгоритмов.

DateInput содержит только два шаблона. В шаблоне dd.MM.uuuu день задаётся как dd, месяц как MM, год как uuuu. ResolverStyle.STRICT отклоняет, например, 31 февраля. Программы отдельно проверяют диапазон года 0001–9999.

## 1. Даты получения и сдачи задания

Класс для запуска — ru.mirea.block2.practical11.Task1.

Читаем дату получения задания и разбираем её по шаблону. Строгая проверка отклоняет несуществующую дату. Проверяем год и то, что дата не находится в будущем. new Date() получает время сдачи из системных часов. Выводим обе даты и фамилию.

Пример ввода

```text
15.09.2026 10:30
```

Результат или его основная строка

```text
Получение задания: 15.09.2026 10:30
```

## 2. Сравнение дат

Класс для запуска — ru.mirea.block2.practical11.Task2.

Переводим введённую строку в LocalDateTime. В текущем времени убираем секунды и наносекунды, потому что ввод содержит только часы и минуты. Через if и else определяем, введённое время раньше, позже или совпадает с текущим.

Пример ввода

```text
31.12.2020 18:00
```

Результат или его основная строка

```text
Введённое время раньше текущего.
```

## 3. Дата рождения студента

Класс для запуска — ru.mirea.block2.practical11.Task3.

В поле birthDate хранится дата рождения. Метод formatBirthDate получает один из трёх стилей и возвращает дату на русском языке. toString() включает дату в среднем формате. В main показываем короткий, средний и полный форматы.

Пример ввода

```text
04.05.2007
```

Результат или его основная строка

```text
Короткий формат: 04.05.2007
Средний формат: 4 мая 2007 г.
Полный формат: пятница, 4 мая 2007 г.
```

## 4. Создание объектов Date и Calendar

Класс для запуска — ru.mirea.block2.practical11.Task4.

Читаем пять чисел и заполняем Calendar. У месяца вычитаем единицу, потому что в Calendar январь обозначен нулём. setLenient(false) включает строгую проверку. getTime() создаёт объект Date с тем же временем.

Пример ввода

```text
2024 2 29
13 45
```

Результат или его основная строка

```text
Calendar: 2024-02-29 13:45
```

## 5. Сравнение ArrayList и LinkedList

Класс для запуска — ru.mirea.block2.practical11.Task5.

Создаём список из 20 000 чисел. По 2 000 раз вставляем в начало, удаляем из начала, добавляем в конец и ищем значение. До и после каждого цикла читаем System.nanoTime(). Разность делим на 1 000 и получаем микросекунды. Повторяем эти действия для ArrayList и LinkedList. Время зависит от компьютера и конкретного запуска.

Программа использует данные, заданные в main.

Выводятся время четырёх операций для каждого списка и число успешных поисков. Для приведённых данных поиск находит значение 2000 раз в каждом списке.
